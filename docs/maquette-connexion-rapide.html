MaquetteConnexion rapide de Portunia. Tapez une adresse puis Entrée : l'identifiant et le mot de passe se saisissent dans le terminal, comme avec PuTTY. Les réglages restent disponibles, mais facultatifs.

Seule l'adresse est demandée

IP, nom ou hôte:port. Entrée ouvre l'onglet SSH aussitôt, sans fenêtre.

Identifiants dans le terminal

« login as: » puis « mot de passe : » masqué. Rien n'est enregistré. Clé SSH ou agent essayés d'abord, en silence.

Options facultatives

Protocole, port, identifiant, mot de passe, clé, bastion : dans la fenêtre « Connexion rapide », repliées par défaut.
