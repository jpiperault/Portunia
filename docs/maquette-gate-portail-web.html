Maquette · Portunia Gate, portail web

Accéder à ses serveurs depuis un navigateur, sans client installé

Une page publique, derrière Cloudflare, qui ne fait qu'une chose : se connecter puis ouvrir les serveurs autorisés, dans le navigateur. Pas d'administration sur cette page. L'administrateur l'active ou la coupe d'un clic dans Portunia. Les écrans se parcourent avec les boutons ; l'onglet Questions rassemble les choix à faire avant de coder, et les réponses s'enregistrent toutes seules.

Portail (navigateur) Portunia
Aucun port entrantLe service Cloudflare Tunnel (cloudflared), installé sur la Gate, ouvre une connexion sortante vers Cloudflare. Le portail n'écoute que sur la Gate lui-même : rien n'est exposé directement à Internet.
Deux portes à franchirCloudflare filtre les robots et les attaques ; Cloudflare Access peut exiger en plus le compte de l'entreprise (Microsoft, Google…). Puis Portunia Gate demande son mot de passe et son code, comme dans Portunia.
Les mêmes règlesLe portail n'est qu'un autre client : mêmes comptes, mêmes règles d'accès, même coffre, même enregistrement signé, même journal. Une session web se relit dans l'audit comme une autre.
Rien à administrer iciLe portail ne montre que les serveurs du compte connecté. Toute l'administration reste dans Portunia (et la ligne de commande).
