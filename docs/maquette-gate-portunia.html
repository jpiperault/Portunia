Ce que l'utilisateur et l'administrateur verront dans Portunia une fois l'étape 2 livrée. L'onglet Questions rassemble les choix à faire avant de coder ; les réponses s'enregistrent toutes seules.

2. Liste des serveursPortunia lit les serveurs autorisés par l'API et les range dans l'arbre.
3. OuverturePour chaque session, un jeton à usage unique : pas de code à retaper.
4. AdministrationComptes, serveurs, règles, journal : mêmes écrans pour qui a le rôle.
