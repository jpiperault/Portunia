Voir, approuver et alerter : le contrôle des accès

Six fonctions qui complètent l'audit : relire les sessions Bureau à distance, ouvrir un serveur Windows avec le compte du coffre, regarder et couper une session en cours, exporter en vidéo, faire approuver un accès sensible, et prévenir quand quelque chose d'inquiétant se passe. Les écrans se parcourent avec les boutons ; l'onglet Questions rassemble les choix à faire avant de coder, et les réponses s'enregistrent toutes seules.

Les numéros de version indiquent un ordre possible ; la dernière question permet de le changer.

Menu ⋯ du bastion › Audit › Sessions : les sessions RDP ont maintenant le bouton « ▶ Relire ». Le lecteur est le même que pour SSH : barre de temps, pauses sautées, vitesse, signature vérifiée. À droite, la frappe (si la règle l'enregistre), les clics et les copier-coller.
