Maquette · Heimdia V1 · module bastion de Portunia

La première version de Heimdia, du serveur jusqu'à Portunia

Le premier onglet montre les écrans de la V1, avec ce qui est inclus et ce qui viendra plus tard. Le second rassemble les questions à trancher avant de coder : vos réponses sont enregistrées au fil de l'eau.

V1 Inclus

  • Proxy SSH : rebond, enregistrement, coffre
  • Comptes locaux + code TOTP
  • Groupes et règles d'accès
  • Enregistrement texte, relecture, recherche
  • Journal d'audit chaîné, export syslog
  • Intégration Portunia + clients SSH standards

Plus tard Prévu

  • Validation par un responsable, vue en direct
  • Bureau à distance (RDP) enregistré
  • Annuaire d'entreprise (AD, Entra, OIDC)
  • Plusieurs nœuds, S3, relais de site
  • Durcissement et certification
